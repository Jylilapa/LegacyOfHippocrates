# Медицинский диагностический портал
## Описание проекта
Проект представляет собой веб-портал для компании медицинской диагностики, предоставляющий информацию об услугах, возможность онлайн-записи на прием и личный кабинет для пациентов.
## Основные функции
📌 Информация о компании и услугах

🗓️ Онлайн-запись на диагностические процедуры

👤 Личный кабинет пациента

📝 История посещений и результатов анализов

📧 Система обратной связи

🔐 Административная панель управления контентом

## Установка и запуск
### Требования
Docker 20.10+

Docker Compose 1.29+
### Инструкция по развертыванию
1. Клонируйте репозиторий:
git clone https://github.com/Jylilapa/LegacyOfHippocrates.git
2. Создайте файл .env на основе .env.example
3. Запустите проект:  `docker-compose up -d --build`
4. Примените миграции: `docker-compose exec web python manage.py migrate`
5. Создайте суперпользователя: `docker-compose exec web python manage.py createsuperuser`
6. Соберите статические файлы: `docker-compose exec web python manage.py collectstatic --no-input`

Проект будет доступен по адресу: http://localhost:8000

Админ-панель: http://localhost:8000/admin
## Администрирование
Для входа в административную панель используйте учетные данные суперпользователя. Доступные разделы:
### Пользователи 
- управление учетными данными пользователей
### Услуги
- добавление и редактирование диагностических услуг
### Доктора
- управление персоналом
### Записи
- управление записями на прием
